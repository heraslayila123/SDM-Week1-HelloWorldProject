# Hello World - Node.js

## About the Project

This is my first Node.js project developed as part of my Week 1 task at SDM Technology.

The project demonstrates the basic setup and execution of a JavaScript application using Node.js.

## Technologies Used

- Node.js
- JavaScript
- Visual Studio Code
- Git
- GitHub

## Features

- Displays Hello World message.
- Prints welcome messages to the console.
- Runs using Node.js.
- Supports execution through npm start.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

   node index.js

Alternatively, run:

   npm start
